How it works

One file holds the whole presentation

  • The slides, fonts, icons and images are all inside this one HTML file.
  • It opens in any desktop browser with a double-click, with no install and no connection.
  • The presenter view, speaker notes and PDF export come with it.

Each bullet appears on its own click. That is a step reveal: add data-step to any element.

Going backwards shows a slide in its finished state, as PowerPoint does.

Fixed by the theme

Going off the template

When no layout fits, a slide can hold anything.

The next three slides show the motion helpers, a custom slide inside the frame, and a full-bleed slide.

Motion

Ready-made motion, one attribute each

fade
The quiet default
rise
Fades in from below
from-left
Slides in from the side
pop
Springs up from small
bounce
Drops in and settles
wipe
Reveals left to right

Also available: drop, from-right, zoom, grow-up and grow-right for bars, draw for SVG lines, travel along a path, data-count for numbers and data-type for typed text.

Add data-anim to an element and it animates when the slide appears. Put data-stagger on the parent to cascade.

Use motion to direct attention, not on every slide. Ordinary content slides are better still.

Custom slide

Anything can go on a slide, as long as it is built from the theme

This wave is drawn by a script that belongs to this slide only. It starts when the slide appears, stops when you leave, and prints as a still frame.

Custom slides carry their own style and script. Both are scoped to the slide, so they cannot disturb the rest of the deck.

Colors come from the theme, so this slide changes with a theme swap like any other.

Full-bleed slides drop the frame

No title position, no margins, no footer. The whole stage is yours.

Use full-bleed for a visual that should take over the screen. The stage is 1920 by 1080.

The rings animate from a start state to the finished slide, so the still version is complete.
