DynamicDecks is a skill you add to an AI agent such as Claude or ChatGPT. When you ask for a presentation, the agent writes it as one HTML file instead of a PowerPoint file.

Because the deck is a web page, slides can move, count, type and react. The rest of this deck shows what that looks like.

A skill is a folder of instructions and tools your agent loads when you ask for a deck. Nothing to host, no editor to learn.

This is the key idea. DynamicDecks is not a slide app. It is a skill: a folder of instructions, a small slide engine, a theme and an icon library that an AI agent reads when you ask it for a deck.

It is built and tested with Claude. It uses the open Agent Skills format, which ChatGPT, Codex and many other agents also read.

Why a web page

Same numbers. One slide just sits there.

Both halves carry the same three facts. The left is what most decks look like. The right took no extra effort to ask for.

Ask for it: “Count each number up and draw its trend underneath.”

Each figure counts up to its value and each trend line draws itself. In the source this is one attribute per element: data-count on the number, data-anim="draw" on the line.

Move

Things that travel across the page

Ask for it: “Drive a truck along the route and light up each stop as it passes.”

The truck follows the line and each stop switches on as it arrives. A journey, a process or a supply chain reads better when the audience watches it happen.

In PowerPoint this is a motion path per object, tuned by hand. Here it is a few lines of script on this slide. Sample data.

Reveal

Build the argument one click at a time

  1. March. A checkout bug cuts sign-ups by 45%.
  2. 2 May. The fix ships and sign-ups climb back.
  3. July. Back above target, and still rising.

Ask for it: “Reveal it in three clicks: the dip, the fix, then the target line.” Press → three times

Press the right arrow three times. First the dip is picked out, then the recovery grows in, then the target line draws across.

You control the pace, so the chart follows what you are saying instead of showing everything at once. Sample data.

React

Slides that answer “what if?” in the room

Annual revenue in 12 months

$3.39M

$0.54M above plan

Ask for it: “Add sliders for growth and churn so we can test the forecast live.” Drag the sliders

Drag either slider and the forecast redraws. When someone asks what happens if growth slows, you answer on the slide instead of promising a follow-up.

Starts from 2.0 million in annual revenue. The plan is 5% new and 2% lost each month. Sample data, for illustration only.

Explain

Diagrams that show the system working

Ask for it: “Draw the architecture and show requests flowing through it.”

The dots are requests travelling the connections, so the audience sees which way the system flows without you tracing it with a pointer.

The diagram is vector graphics drawn in the deck's theme colors. Nothing here is an image.

Anything

If a browser can draw it, a slide can show it.

This background is live code. Move your pointer across it.

Ask for it: “Make the background a network that reacts to my pointer.”

Move the pointer over the slide: the network bends toward it. This is a canvas drawn sixty times a second in the theme's colors.

The point is not this effect. It is that anything a web page can do is available: maps, simulations, video, 3D, live calculators.

Works offline

Fonts, icons and images are inside the file. It loads nothing.

Press S for the presenter window, O for the overview, P to save a PDF and question mark for the full list of shortcuts.

The presenter window and PDF export need the downloaded file opened in a browser. They do not work in the preview pane of an AI assistant.

Edit mode is how you ask for changes: press E, click the thing you mean, and paste the copied reference into your message to the agent.

Your brand

One theme restyles every slide

Colors, type, spacing and motion live in one theme. Give your agent a PowerPoint template or a brand guide and it builds yours.

Try it, then go back a few slides. The charts, the truck and the network all followed.

Ask for it: “Turn our PowerPoint template into a theme and rebuild this deck in it.”

Click Dark or Light, or press T anywhere in the deck. Every slide changes, including the custom ones, because they are built from the theme's named values rather than fixed colors.

A theme can be made from a PowerPoint template, a brand guide, or a few colors and fonts. You can also add your own icon set.

Get started

Add the skill, ask for a deck, open the file

  1. Add the skill

    Upload it to Claude, or drop the folder where your agent keeps skills.

  2. Ask for a deck

    Say what it is for and paste in your notes, numbers or template.

  3. Open and present

    Double-click the file. Press F for full screen and S for your notes.
